# CBB - CineBookBeats

> One Mood, Three Worlds - Movie, Book & Music.

**CBB** is a simple, fast, and beautiful web app that helps you discover your next favourite **Movie, Book, and Music** based on your language.

No login. No sign-up. Just pick your language, pick your category, and explore.

**Live Demo:** [Click Here To Try CBB]

https://samriddha-pal.github.io/CineBookBeats/

## ✨ Features

- **3 Languages Supported:** Bengali, English, Hindi
- **3 Categories:** Movies, Books, Music
- **Curated Lists:** Hand-picked popular & classic titles with real details
- **A-Z Sorted List:** All titles are sorted alphabetically with numbering (1, 2, 3...)
- **Different Ratings:** Every title has its own unique rating (e.g. 4.6, 4.9, 5.0)
- **Real Details:**
    - Books: Author + Genre
    - Movies: Director + Cast + Genre
    - Music: Singer + Album / Movie + Mood
- **Live Search:** Search by Title, Author, Director, or Singer instantly
- **Mobile-First Design:** Beautiful glassmorphism UI, works perfectly on mobile
- **No Part / Vol Issue:** Clean titles, no confusing parts/volumes

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Design:** Glassmorphism, Gradient UI
- **Data:** In-built curated JavaScript Database (No backend needed)
- **Deployment:** GitHub Pages / Netlify / Vercel

## 📂 Project Structure

The entire app is in a single `index.html` file for easy deployment and fast loading.

## 🚀 How To Run

**Option 1: Directly**
1. Download / Clone this repo
2. Double-click on `index.html`
3. Done! It will open in your browser.

**Option 2: With Live Server (VS Code)**
1. Open folder in VS Code
2. Right-click on `index.html` > Open with Live Server

## 🎯 How To Use

1. **Step 1:** Select Language - Bengali / English / Hindi
2. **Step 2:** Select Category - Movie / Book / Music
3. **Step 3:** Browse the full A-Z list with ratings
4. **Step 4:** Use the search bar to find a specific title, author, or singer.
